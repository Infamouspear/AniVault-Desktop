# AniVault Desktop 1.4.1

This update adds scan-time storage indexing for local anime video and manga
archives or image folders. Rescan both libraries to populate existing entries.
Partial totals exclude unknown sizes, unavailable files, and Restricted entries.

Home resume thumbnails are smaller and preserve the artwork composition.
Franchise names use two-line truncation. Manga, Discover and Airing use updated
headers, controls or compact cards. Continue Watching and Recently Added remain
on Home, and status lists remain in Collections.
